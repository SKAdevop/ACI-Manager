Project details and information

ACI Manager ToolSet

This application provides a comprehensive operations dashboard and automation interface for Cisco ACI (Application Centric Infrastructure) deployments. Built to interact dynamically with the Cisco APIC controller, it enables users to visualize tenants, EPG mappings, subnets, and leaf switch interfaces, while providing copyable automation templates for provisioning fabric resources.
